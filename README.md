### 🚀 Featured Projects

**[Half-Duplex UART Communication Controller — FPGA](https://github.com/hemumafia/UART-protocol-half-duplex)**
Verilog HDL · Xilinx Vivado · Basys3 (Artix-7) · Python
- Designed and verified a half-duplex UART controller from scratch — custom TX/RX RTL cores, FSM-based protocol controller, self-checking testbench.
- Closed timing across **all 177 endpoints** in Vivado: **+5.268 ns** setup slack, **+0.151 ns** hold slack, **~211 MHz** Fmax, on **83 LUTs / 102 registers** at **0.073 W**.
- Validated end-to-end on physical Basys3 hardware via a Python/PySerial host script over USB-UART.

**[Joystick-Controlled EV Motor Controller Prototype](https://github.com/hemumafia/Joystick-Controlled-EV-Motor-Controller)**
Arduino Uno · L298N H-Bridge · C++
- Built a dual-channel PWM motor control system independently driving two TT gear motors from a 2S Li-ion source.
- Implemented dead-zone and minimum-PWM thresholding to eliminate stall at low command values; validated control loop at 10 Hz polling.
- Designed a shared-ground architecture across battery, MCU, and motor driver for stable PWM signal reference.
